## Notas Técnicas

- **Padrão seguido:** Igual ao `loadData` de `src/routes/conteudo.tsx` (linhas 665-715 aprox.)
- **Filtro `isDeleted: { $ne: true }`:** Inclui os 7 registros legados que têm `isdeleted` NULL no Supabase (o RxDB já os sincronizou corretamente).
- **Single query para tópicos:** Busca todos os tópicos do usuário de uma vez e agrupa em memória (`topicsMap`), evitando N+1 queries.
- **Offline-first:** Funciona sem token de autenticação; dados vêm do IndexedDB via RxDB.
- **Props públicas mantidas:** `userId`, `selectedTopicIds`, `onChange`, `allowMultiple` inalteradas.
- **Não alterado:** `getDisciplines`/`getTopics` em `supabaseClient.ts` (outros consumidores podem depender).
