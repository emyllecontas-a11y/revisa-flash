### 2.1 Funções de criação (assinaturas exatas)

| Função | Parâmetros | Retorno | Enqueue |
|--------|------------|---------|---------|
| `createStudyTask(data: Omit<StudyTask, 'id' \| 'user_id' \| 'created_at' \| 'updated_at' \| 'isDeleted'>)` | `name, activity_type, color, theme_rule, default_duration_min` | `Promise<StudyTask>` | `enqueueOperation('create', 'study_tasks', task)` |
| `createStudyThemeTimeline(data: Omit<StudyThemeTimeline, 'id' \| 'user_id' \| 'created_at' \| 'updated_at' \| 'isDeleted'>)` | `period_type, period_start, themes, topic_ids?` | `Promise<StudyThemeTimeline>` | `enqueueOperation('create', 'study_theme_timelines', timeline)` |
| `upsertStudyThemeTimeline(data: Omit<...>)` | Mesmo acima, faz upsert por `period_type + period_start` | `Promise<StudyThemeTimeline>` | `enqueueOperation('update' \| 'create', ...)` |
| `createStudyWeeklyBlock(data: Omit<StudyWeeklyBlock, 'id' \| 'user_id' \| 'created_at' \| 'updated_at' \| 'isDeleted'>)` | `task_id, weekday, start_time, end_time, effective_from, effective_until?` | `Promise<StudyWeeklyBlock>` | `enqueueOperation('create', 'study_weekly_blocks', block)` |
| `createStudyExtraEvent(data: Omit<StudyExtraEvent, 'id' \| 'user_id' \| 'created_at' \| 'updated_at' \| 'isDeleted'>)` | `task_id, weekdays[], start_time, end_time, week_starts[]` | `Promise<StudyExtraEvent>` | `enqueueOperation('create', 'study_extra_events', event)` |

### 2.2 Padrão de upsert idempotente
- **StudyThemeTimeline**: `upsertStudyThemeTimeline` busca por `user_id + period_type + period_start + isDeleted !== true`
- **StudyTask**: **NÃO existe** busca por nome. Será necessário criar `findStudyTaskByName` ou `upsertStudyTaskByName`
- **StudyWeeklyBlock**: Upsert por `task_id + weekday + start_time + effective_from` (não existe função pronta)
- **StudyExtraEvent**: Não tem upsert (cria direto)

### 2.3 Helpers existentes
- `getCurrentUserId()` → lê `localStorage.getItem('revisaflash_user_id')`
- `assertUserId()` → lança erro se não autenticado
- `nowISO()` → `new Date().toISOString()`
- `uid()` (importado de `@/utils/helpers`) → gera ID único

### 3.1 Interfaces principais (campos exatos)

```typescript
// StudyTask (Camada 2 - Biblioteca)
interface StudyTask {
  id: string;
  user_id: string;
  name: string;
  activity_type: ActivityType; // 'theory' | 'questions' | 'review' | 'cards' | 'exam' | 'break' | 'other'
  color: string; // hex
  theme_rule: ThemeRule; // 'period' | 'all' | 'none'
  default_duration_min: number;
  created_at: string;
  updated_at: string;
  isDeleted?: boolean;
}

// StudyThemeTimeline (Camada 1 - Linha do Tempo)
interface StudyThemeTimeline {
  id: string;
  user_id: string;
  period_type: PeriodType; // 'month' | 'week'
  period_start: string; // ISO date
  themes: string[]; // nomes dos temas
  topic_ids?: string[]; // UUIDs dos tópicos (integração Conteúdos)
  created_at: string;
  updated_at: string;
  isDeleted?: boolean;
}

// StudyWeeklyBlock (Camada 3 - Padrão Semanal)
interface StudyWeeklyBlock {
  id: string;
  user_id: string;
  task_id: string;
  weekday: Weekday; // 0=Dom..6=Sáb
  start_time: string; // HH:MM
  end_time: string; // HH:MM
  effective_from: string; // ISO date
  effective_until?: string | null;
  created_at: string;
  updated_at: string;
  isDeleted?: boolean;
}

// StudyExtraEvent (Camada 4 - Exceções)
interface StudyExtraEvent {
  id: string;
  user_id: string;
  task_id: string;
  weekdays: Weekday[];
  start_time: string;
  end_time: string;
  week_starts: string[]; // ISO dates
  created_at: string;
  updated_at: string;
  isDeleted?: boolean;
}
```
